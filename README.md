# Змейка для iPhone

Игра на Flutter. GitHub сам собирает из неё файл `Snake.ipa` при каждом изменении кода.

1. Загрузить все файлы в новый репозиторий на GitHub (ветка `main`).
2. Открыть вкладку **Actions** и дождаться зелёной галочки (около 10 минут).
3. Скачать `Snake.ipa` в разделе **Releases**.
4. Установить на iPhone через Sideloadly с обычным Apple ID.
5. На iPhone включить: Настройки → Конфиденциальность и безопасность → Режим разработчика.
